## 👨‍💻 Sobre mim

Olá! Sou desenvolvedor de software com foco em **Frontend Development**, experiência prática em desenvolvimento Backend e atuação na construção de aplicações web de ponta a ponta.

Minha principal stack é **TypeScript, React e Next.js**, com foco na criação de interfaces modernas, componentes reutilizáveis, arquitetura organizada e aplicações com boa manutenibilidade.

Além do Frontend, tenho experiência com desenvolvimento Backend e integração de APIs REST, o que me permite compreender melhor a comunicação entre as diferentes camadas de uma aplicação e contribuir para soluções completas.

Atualmente, estou na etapa final da graduação em **Análise e Desenvolvimento de Sistemas pela FATEC Taubaté**, aprofundando meus conhecimentos em arquitetura de software, desenvolvimento web e boas práticas de programação.

### 🎯 Principais interesses

- ⚛️ Desenvolvimento Frontend com React e Next.js.
- 🧩 Arquitetura de software, modularização e reutilização de código.
- 🔗 Integração entre aplicações Frontend e APIs REST.
- ⚙️ Desenvolvimento Backend e construção de serviços.
- 🐳 Containerização e ambientes de desenvolvimento com Docker.
- 🤖 Inteligência Artificial e novas tecnologias aplicadas ao desenvolvimento.
